# ヨミピク（YomiPic）

漫画・小説の人気ランキングをチェックし、評価や感想を投稿できる読書コミュニティサイト。

## コンセプト

**次に読む一冊が、きっと見つかる。**

ランキング、短い感想、読みたい保存を中心に、学生や若い読者がスマホで気軽に作品を発見できるサービスを目指します。

## 現在の初期版

- 漫画 / 小説ランキング切り替え
- 今週人気 / 急上昇 / 高評価の切り替え
- 作品検索
- 読みたい保存
- 星評価・気分タグ・ひとこと感想投稿
- スマートフォン対応

> 現在表示している作品はUI確認用の架空データです。実作品データ/API連携は次の開発段階で追加予定です。
